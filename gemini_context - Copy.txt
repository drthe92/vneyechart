## 3. CÔNG NGHỆ & TỔNG QUAN HỆ THỐNG

- **Frontend**: Vanilla JavaScript (ES6 Modules, `import`/`export`),
  HTML5 Canvas 2D, WebGL, SVG. KHÔNG dùng framework (React/Vue).
- **State**: object `state` (js/main.js) — `currentTest`, `steps`,
  `stepIndex`, `history` (stack BACK). Không có store trung tâm;
  truyền qua biến module + `window.__*`.
- **Storage**: `localStorage` (offline-first), tối đa 200 bản ghi EMR.
- **Backend y khoa phụ trợ**: `neuro_ophthalmology/` là app **Python +
  Pygame** chạy độc lập (OKN, Red Desaturation, menu cấu hình màn hình),
  không giao tiếp trực tiếp với webapp JS — tách biệt hoàn toàn.
- **Kiến trúc**: Module-based, dynamic registry, Global Event Delegation.
  Webapp là SPA đo thị lực + Mini-EMR cho phòng khám nhãn khoa.

## 4. HỢP ĐỒNG MODULE BÀI TEST (DIAGNOSTIC)

Mọi bài test thị lực là một object đăng ký qua `registerTestModule(mod)`:

```javascript
const mod = {
  id: 'far-vision-tumbling-e',   // phải khớp data-test trong index.html
  label: 'Tumbling E',
  steps: [1.0, 0.9, ..., -0.3],  // mảng bước (thường là LogMAR levels)
  _state: ...,                    // trường nội bộ tuỳ ý

  render(index) {                 // BẮT BUỘC: vẽ bước thứ index vào #display-board
    const logmar = this.steps[index];
    const pxSize = getOptotypeSize(logmar, calib);
    document.getElementById('display-board').innerHTML = `...svg...`;
  },

  cleanup()  { /* TÙY CHỌN: dọn loop (vd OKN/Maddox) khi chuyển test */ },
  randomize() { /* TÙY CHỌN: xáo lại ký tự, GIỮ nguyên LogMAR */ },
};
registerTestModule(mod);
```

- `loadTest(testId, steps)`: gọi `prevMod.cleanup()`, push history,
  reset `stepIndex=0`, `renderStep()`. Luôn `universalInput.resume()`.
- `renderStep()`: gọi `mod.render(state.stepIndex)` vào `#display-board`.
- Điều hướng: ArrowRight/Down/Enter/PageDown → NEXT (index++);
  ArrowLeft/Up/PageUp → PREV; Escape/Backspace → BACK (pop history);
  Space → SHUFFLE (gọi `mod.randomize()` hoặc `renderStep()`).
- Sidebar click: nếu `id.startsWith('near-vision-')` → `applyNearVisionPreset()`
  (0.4m); `far-vision-` → `applyDistanceVisionPreset()` (4m).

## 5. HỆ THỐNG INPUT CHUẨN (UniversalInput)

`js/controller.js` — phát `CustomEvent` lên `document`, tách biệt hoàn
toàn khỏi logic module:

```javascript
document.addEventListener('app:next',    () => nextStep());
document.addEventListener('app:prev',    () => prevStep());
document.addEventListener('app:back',     () => back());
document.addEventListener('app:shuffle',  () => shuffleStep());
```

- Nguồn: Keyboard / Mouse / Wheel(throttle 250ms) / Touch swipe / Gamepad.
- Phím: →↓Enter PgDn = NEXT; ←↑ PgUp = PREV; Esc/Bksp = BACK; Space = SHUFFLE;
  keyCode 123 (F12) = NEXT.
- Bỏ qua input khi focus trong `INPUT/TEXTAREA/SELECT/BUTTON/.exam-modal`
  hoặc khi `isSuspended=true` (module có custom controls tự gọi `suspend()`).
- `throttle(fn, cooldown)`: trailing+leading edge.

## 6. HIỆU CHUẨN QUY MÔ VẬT LÝ (Calibration)

### 6.1 Công thức kích thước optotype (js/calibration.js)
```javascript
// h_mm = D_mm * tan(5' * 10^logmar);  px = h_mm * (ppi / 25.4)
arcminutes = 5 * Math.pow(10, logmar);
radians    = (arcminutes / 60) * (Math.PI / 180);
heightMm   = (distanceM * 1000) * Math.tan(radians);
heightPx   = heightMm * (ppi / 25.4);   // số thực, KHÔNG round/clamp
getOptotypeSize(logmarValue, calib={distanceM, ppi}) -> heightPx
```
- `DisplayCalibrator` lưu `distanceM` (mặc định 4m; near 0.4m).
- **Ưu tiên nguồn PPI** (quan trọng nhất cho độ chính xác lâm sàng):
  1. Credit-card calibration: `localStorage['vision-therapy-cc-pxpermm']`
     → `ppi = pxPerMm * 25.4`
  2. `window.__calibrator.pxPerMm` (DisplayCalibrator)
  3. Fallback ước lượng: `diagPx / 24 inch` (không chính xác)
- `CreditCardCalibrator`: thẻ chuẩn 85.6 × 53.98 mm. Kéo slider khớp
  mép thẻ → `pxPerMm = sliderPixels / 85.6`, `ppi = pxPerMm * 25.4`.
  Lưu vào `localStorage['vision-therapy-cc-pxpermm']`. Cảnh báo Zoom 100%.

### 6.2 Pygame calibration (neuro_ophthalmology/calibration.py)
```python
PPD = d_mm * tan(pi/180) * R / W        # pixels per degree
stripe_width_px = PPD / (2 * cpd)        # 1 cycle = 2 stripes
velocity_px_s   = PPD * ang_vel_deg_s
```
- `ScreenInfo`: lấy `res_w/res_h` từ pygame, tính `physical_width_mm`,
  `ppi`, `ppd`, `px_per_mm`. `set_distance(mm)`, `set_diagonal(inches)`.

## 8. HỢP ĐỒNG GAME HUẤN LUYỆN (THERAPEUTIC)

Game kế thừa `BinocularGameEngine` (modules/binocular_game_engine.js):
- `this.gameName` (vd `'M1: Hứng hạt (Anti-suppression)'`).
- `super()` kiểm tra `window.__anaglyphColors`, tạo canvas, bind SPA.
- Kết thúc: dispatch `CustomEvent('onTherapeuticSessionEnd', {detail:
  {timestamp, durationMs, metrics, opticalSettings}})`.
- `main.js` bắt sự kiện → build `therapyRecord`:
  `{id, timestamp, gameName, durationSeconds, metrics, opticalSettings}`
  → `examSessionManager.addTherapyRecord(record)`.
- `metrics.customData` chứa chỉ số lâm sàng: `finalAlpha` (M1 C-Ratio),
  `visualAngleDeg` (M2), `avgBaseOut/avgBaseIn` (M3 BO/BI),
  `finalArcsec` (M5 stereo RDS), `avgLatencyMs` (M4, ngưỡng Fitts
  500ms cảm ứng / 900ms chuột).
- `formatTherapyClinicalResult` / `generateTherapyReportHTML` (main.js)
  parse `customData` → chuỗi kết quả + ĐẠT/CHƯA ĐẠT.

## 13. SƠ ĐỒ LUỒNG DỮ LIỆU (ASCII)

### 13.1 Khởi động (Boot)
```
index.html
   │
   └─<script type="module" src="js/main.js">
         │
         ▼
   main.js :: init()
         ├─ setupSidebar()        → gắn click .menu-item, điều hướng D-Pad

         ├─ setupDisplay()        → DisplayManager (#app, autoApply)

         │                          → window.__calibrator / window.__ccCal
         ├─ setupWorkspaceToggle()→ #workspace-toggle-btn
         └─ loadTest(state.currentTest, mod.steps) → renderStep()
```

### 13.2 Hiệu chuẩn (Calibration pipeline)
```
CreditCardCalibrator.showModal()
   └─ user kéo slider khớp thẻ 85.6mm
         └─ _saveAndSync(px) → localStorage['vision-therapy-cc-pxpermm']
               └─ DisplayCalibrator._recalculate()
                     pxPerMm = savedPx/85.6 ; ppi = pxPerMm*25.4
                           │
                           ▼
   getOptotypeSize(logmar, {distanceM, ppi})
       = (distanceM*1000)*tan((5*10^logmar/60)*π/180) * (ppi/25.4)
                           │
                           ▼
   module.render(index) → #display-board (SVG/Canvas kích thước px chuẩn)
```

### 13.3 Bài test (Diagnostic flow)
```
[Sidebar .menu-item click]
   → loadTest(testId, mod.steps)
        → prevMod.cleanup()  (dọn loop nếu có)
        → UniversalInput.resume()
        → state.history.push(...) ; state.stepIndex=0
        → renderStep() → mod.render(idx) vào #display-board
   [UniversalInput CustomEvent]
        app:next  → nextStep()  (idx++)
        app:prev  → prevStep()  (idx--)
        app:back  → back()      (pop history)
        app:shuffle → mod.randomize() (giữ LogMAR)
   [Sidebar near-*/far-*] → auto applyNearVisionPreset()/applyDistanceVisionPreset()
```

### 13.4 Huấn luyện (Therapeutic flow)
```
#workspace-toggle-btn → toggleWorkspace() → 'therapeutic'
   → onWorkspaceChanged event → TherapeuticMenuController.init()
   → [Chọn game M1..M6] → _renderLobby() (hướng dẫn lâm sàng)
        → btn-start-fullscreen → _startFullscreenGame()
             → new module.classRef() ; game.start(config)
                  │ (game kế thừa BinocularGameEngine, dùng window.__anaglyphColors)
                  ▼
             game kết thúc → dispatch 'onTherapeuticSessionEnd'
                  {timestamp, durationMs, metrics, opticalSettings}
                  │
                  ▼
             main.js → build therapyRecord
                  → examSessionManager.addTherapyRecord(record)
                  → localStorage['emr_patient_sessions']
   [Phác đồ tự động] CatchGame→'requestLaunchModule2'→M2; M2→M3; RDS→M6
```
